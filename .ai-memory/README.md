# Memoria compartida de Kermesse

Esta carpeta contiene únicamente conocimiento estable y revisado del proyecto.
Se versiona en Git para que Codex, Claude y Antigravity puedan compartir contexto entre equipos.

No guardar aquí contraseñas, tokens, datos personales, prompts completos ni logs.

## Flujo

1. Leer los archivos relevantes antes de trabajar.
2. Actualizar la memoria cuando una decisión sea importante para futuras sesiones.
3. Hacer commit de los cambios de memoria junto con el cambio de código relacionado.

## Índice

- `architecture.md`: arquitectura que ya está implementada o aprobada para varios módulos.
- `decisions.md`: decisiones técnicas, funcionales y comerciales aprobadas.
- `hitos.md`: hoja de ruta, entregables, dependencias y estado de cada hito.
- `known-issues.md`: riesgos, problemas conocidos y bloqueos vigentes.
- `current-task.md`: objetivo inmediato de la sesión activa.

Para retomar el proyecto en otro agente o equipo, leer primero este archivo, después
`hitos.md`, `decisions.md`, `current-task.md`, `docs/PLAN_DE_TRABAJO_KERMESSE.md` y
`docs/REGLAS_DE_NEGOCIO.md`.
